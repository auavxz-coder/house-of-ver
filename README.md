# HOUSE OF VÈR — Streamlit website

Bilingual English/Arabic perfume showcase, AED 225 / 100 ml, UAE delivery and Instagram DM ordering. No checkout or online card processing.

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Publish for free on Streamlit Community Cloud

1. Create a public GitHub repository (for example `house-of-ver-site`).
2. Upload `app.py`, `requirements.txt`, and the `assets/` folder to the repository.
3. Sign in at https://share.streamlit.io and choose **Create app**.
4. Select your repository, branch `main`, and entrypoint `app.py`, then deploy.
5. Test the English/Arabic switch and Instagram DM button on mobile.

## Edit content

Change product price, language strings, and Instagram handle in `app.py`. Replace `assets/perfume.jpg` with your approved product photograph. `assets/brand_art.png` is your previously supplied HOUSE OF VÈR gold-cloud design.

Note: the Instagram direct-chat link may vary by device/login. A profile fallback is included. Delivery fees/timing must be confirmed by DM. Before taking orders, obtain required UAE business licence and product approvals.
